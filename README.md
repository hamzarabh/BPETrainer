
# BPETrainer

A small educational implementation of the **Byte Pair Encoding (BPE)** tokenizer algorithm using Python.

BPETrainer demonstrates how a tokenizer learns subword tokens from text, encodes text into token IDs, and decodes token IDs back into text.

## Features

- Train a tokenizer on a text dataset.
- Learn merge rules from frequently occurring adjacent symbols.
- Build a vocabulary of tokens and their IDs.
- Encode text into token IDs.
- Decode token IDs back into readable text.
- Save the trained vocabulary and merge rules in `tokenizer.json`.
- Use a command-line interface powered by [Google Fire](https://github.com/google/python-fire).
- Validate input data with [Pydantic](https://docs.pydantic.dev/).

## Usage

Run the CLI from the project root:

```bash
uv run python -m src <command> <arguments>
```

### 1. Train the tokenizer

Train the tokenizer with a target vocabulary size:

```bash
uv run python -m src train 5000
```

The project uses its default dataset when no dataset path is supplied. The dataset may need to be downloaded before training begins.

To use a custom dataset, provide its path using the `data_path` argument if supported by the current CLI configuration:

```bash
uv run python -m src train 5000 --data_path=./data.txt
```

After training, the tokenizer writes its vocabulary and merge rules to `tokenizer.json`.

**Note:** The vocabulary size is a training target. The final vocabulary size may differ depending on the implementation and available merge rules.

### 2. Encode text

Convert text into token IDs:

```bash
uv run python -m src encode "hello world"
```

Example output:

```text
(2589, 4, 4, 11, 2601, 2625, 11110)
```

The token IDs above are illustrative; actual IDs depend on the trained tokenizer.

### 3. Decode token IDs

Pass the token IDs produced by the encoder to the decoder:

```bash
uv run python -m src decode "(2589, 4, 4, 11, 2601, 2625, 11110)"
```

The expected result for matching token IDs and tokenizer vocabulary is:

```text
hello world
```

Use IDs from your own encoder output. Decoding requires a compatible `tokenizer.json` generated by the tokenizer.

## How BPE Works

BPE learns subword tokens by repeatedly merging frequent adjacent symbols.

1. **Initialize:** Split words into smaller symbols.
2. **Count pairs:** Calculate the frequencies of adjacent symbol pairs.
3. **Merge:** Select a frequent pair and merge its symbols.
4. **Repeat:** Continue until the training target is reached or no eligible pairs remain.
5. **Save:** Store the learned vocabulary and merge rules.
6. **Encode:** Apply the merge rules to new text and map tokens to IDs.
7. **Decode:** Map IDs back to tokens and reconstruct the text.

## Limitations

This project is intended for learning and experimentation.

- It is not a production-ready tokenizer.
- Tokenization behavior depends on the implementation and training data.
- The encoder and decoder require a compatible trained vocabulary.
- Unknown-token handling and Unicode edge cases may require additional work.
- Training quality depends on the dataset and merge implementation.

## Learning Goals

BPETrainer is designed to help learners understand:

- How subword tokenization works.
- How merge rules are learned.
- How vocabularies map tokens to integer IDs.
- How encoding and decoding depend on the same tokenizer.
- How to build a small Python package with a command-line interface.
